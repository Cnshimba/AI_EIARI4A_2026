1. What is AI?

The Definition

Artificial Intelligence (AI) is the branch of computer science dedicated to creating systems capable of performing tasks that typically require human intelligence.

Key Insight: "AI is whatever has not been done yet" — The AI Effect

The Hierarchy of Intelligence

Artificial Narrow Intelligence (ANI):

  • Specialized systems excelling at single tasks

  • Examples: DeepBlue (chess), Google Maps, ChatGPT

  • Current State: This is where we are today

Artificial General Intelligence (AGI):

  • Human-level reasoning across diverse domains

  • Can learn any intellectual task

  • Status: Theoretical/hypothetical

Artificial Super Intelligence (ASI):

  • Surpasses human intellect in every field

  • Including creativity and social skills

  • Status: Speculative future

2. A Brief History of AI

Key Milestones

1956 - The Birth:

  • Dartmouth Conference

  • John McCarthy coins "Artificial Intelligence"

  • Logic Theorist proves mathematical theorems

1974-1980 - First AI Winter:

  • Logic-based systems fail on real-world complexity

  • Funding dries up, skepticism grows

  • "Gloomy Period"

1980s - Expert Systems Era:

  • Corporate "if-then" rule engines

  • Knowledge Period returns

  • Brittle and expensive to maintain

2010s-Present - Deep Learning Revolution:

  • Big Data + Cloud Computing + GPUs

  • Systems learn from data, not rules

  • Vision, language, creativity breakthroughs

Section 1 Checkpoint

Summary

  • AI is creating systems that perform tasks requiring human intelligence

  • We are currently in the ANI (Weak AI) era

  • AI history is cyclical: hype → winter → rebirth

  • Current era powered by Deep Learning (learning from data)

Key Insight

The "AI Effect" constantly moves goalposts—yesterday's AI becomes today's standard software

3. The Three Schools of Thought

Symbolism (Logic)

"Thinking is Computing"

Concept: Intelligence = symbol manipulation via logical rules

Mechanism:

  • Explicit programming: If Bird(x) then Fly(x)

  • Physical symbol systems

Strengths: Chess, theorem proving, planning

Weaknesses: Perception, learning from raw data (can't write rules for "cat")

Example: Deep Blue, Expert Systems

Connectionism (Neural Networks)

"Thinking is Biological"

Concept: Intelligence emerges from networks of simple processing units

Mechanism:

  • Mimics brain's neural structure

  • Learn patterns by adjusting connection weights

  • Foundation of modern Deep Learning

Strengths: Messy tasks—vision, speech, language

Status: Dominant school today (ChatGPT, Computer Vision)

Example: All modern Deep Learning systems

Behaviorism (Evolution)

"Intelligence is Action"

Concept: Adapt behavior through environment interaction

Mechanism:

  • Perception → Action loops

  • No complete internal world model needed

  • React correctly to stimuli

Strengths: Robotics, physical world interaction

Example: Boston Dynamics robots, Reinforcement Learning

Section 2 Checkpoint

The Three Philosophies

  • Symbolism: Explicit logic rules (GOFAI—Good Old-Fashioned AI)

  • Connectionism: Neural networks learning from data (Current dominant)

  • Behaviorism: Evolution through action (Robotics, RL)

Reflection

Why did Connectionism become dominant in the 2010s?
Answer: Convergence of Big Data, GPUs, and scalable algorithms

4. The AI Triad: Key Elements

Modern AI requires three pillars to succeed:

1. Data (The Fuel)

  • Big Data provides training examples

  • Without data, models cannot learn

2. Algorithms (The Engine)

  • Mathematical techniques: CNNs, Transformers, Regression

  • Process data to extract patterns

3. Computing Power (The Chassis)

  • GPUs, TPUs, NPUs, Ascend Chips

  • Execute billions of matrix operations

Together: These create the modern AI revolution

5. Key AI Domains

Machine Learning (ML)

Learning from data without explicit programming

Traditional: You write rules
ML: Machine discovers rules from data + answers

Deep Learning (DL)

Neural networks with multiple layers

Learns hierarchical representations
Example: Lines → curves → shapes → car

Natural Language Processing (NLP)

Computers understanding human language

Translation, sentiment analysis, text generation
Powers: ChatGPT, Google Translate

Robotics

Physical manifestation of AI

Perception (sensors) → Planning → Action (motors)
Example: Boston Dynamics, autonomous vehicles

6. The AI Ecosystem

The Four Pillars

  1. Data: Training examples and memory
  2. Algorithms: Mathematical engines (CNNs, Transformers)
  3. Computing Power: Specialized hardware (GPUs, TPUs)
  4. Scenarios: Real-world problems and use cases

The Relationship Triangle

  • Cloud Computing: The body (storage, compute)

  • Big Data: The memory (training material)

  • IoT: The nervous system (sensors, edge execution)

  • AI: The brain (processes and decides)

7. AI Hardware: The Compute Layer

Why Not Just CPUs?

CPUs excel at sequential logic but are terrible at parallel matrix math required for Deep Learning.

The Specialists

GPU (Graphics Processing Unit) - The Labor Force:

  • Thousands of simple cores

  • Massive parallel processing

  • Workhorse of AI revolution (NVIDIA A100)

TPU (Tensor Processing Unit) - Google's ASIC:

  • Hardwired for TensorFlow

  • Faster and more efficient than GPUs

  • Application-specific, cannot be reprogrammed

FPGA - The Shape Shifter:

  • Rewirable via software

  • Updated hardware without replacing silicon

  • Microsoft Azure uses extensively
