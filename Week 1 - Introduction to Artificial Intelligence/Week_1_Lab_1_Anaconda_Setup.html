Introduction to Artificial Intelligence

Lab: Environment Setup (Anaconda)
Lab Goal: To install Anaconda, configure your first Python Environment, and launch Jupyter Lab.

Why Anaconda?
In AI, we use thousands of external libraries. Managing them manually is a nightmare. Anaconda is a tool that manages them for us. It creates isolated "boxes" (environments) so that Project A's tools don't break Project B.

[!NOTE]
Prerequisites: A computer with Windows, Mac, or Linux. Admin rights might be required for installation.

Part 1: Installing Anaconda

Anaconda is the standard distribution for Data Science. It comes with Python and the most popular libraries pre-packaged.

Step 1: Download

  1. Go to the Official Anaconda Website.
  2. Download the Python 3.x Graphical Installer for your operating system.

Step 2: Install

  1. Run the installer.
  2. Important: If asked, DO NOT check "Add Anaconda to my PATH environment variable" (unless you know what you are doing). It is safer to use the Anaconda Prompt.
  3. Click Next/Finish until installed.

Step 3: Verify

  1. Open Anaconda Prompt (Windows) or Terminal (Mac/Linux).
  2. Type the following command and hit Enter:
conda --version

If you see a version number (e.g., conda 23.7.0), you are ready!

Part 2: Creating Your AI Environment

We never work in the "base" environment. We create a custom one for our course.

Step 1: Create the Environment

In your Anaconda Prompt, run:

conda create --name ai_env python=3.10

  • create: Tells conda to make a new box.

  • --name ai_env: Names the box "ai_env".

  • python=3.10: Installs Python version 3.10 inside it.

Type y and hit Enter when asked to proceed.

Step 2: Activate the Environment

To enter the box, run:

conda activate ai_env

You should see (ai_env) appear on the left side of your command prompt.

Part 3: Installing Libraries

Now that we are inside our "clean box", let's install the Data Science Triad we learned about in the lectures.

Run this command:

conda install jupyter numpy pandas matplotlib

  • Jupyter: The notebook interface we will use to write code.

  • NumPy: Math library.

  • Pandas: Data library.

  • Matplotlib: Charting library.

Type y to confirm installation.

Part 4: Launching Jupyter Lab

This is where we will write all our code for the semester.

  1. In the same terminal (ensure (ai_env) is active), run:
jupyter lab
  1. A web browser window should pop up automatically.
  2. Click the Python 3 (ipykernel) button under "Notebook" to start a new file.
Success: If you see a blank cell ready for code, CONGRATULATIONS! You represent the top 1% of people who actually set up their environment correctly.

Part 5: Your First AI Code

Let's test if everything works. Copy this code into the first cell and press Shift + Enter to run it.

import numpy as np
import matplotlib.pyplot as plt

# 1. Generate random data
data = np.random.randn(1000)

# 2. Plot a histogram
plt.hist(data, bins=30, color='skyblue', edgecolor='black')
plt.title("My First AI Environment Test")
plt.show()

Result: You should see a blue bell-curve chart.

Summary

You have successfully:
1. Installed Anaconda.
2. Created a dedicated ai_env.
3. Installed the core AI libraries.
4. Ran your first Jupyter Notebook.

You are now ready for Week 2!
