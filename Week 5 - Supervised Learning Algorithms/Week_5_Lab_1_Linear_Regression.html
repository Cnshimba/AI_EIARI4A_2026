Foreword

This lab introduces common machine learning algorithms to help you better understand their functions and usages. Specifically, it will explain how to build a linear regression algorithm from scratch and implement it using scikit-learn.

Lab Goal
In this section, we use the sklearn library to perform simple linear regression on a small (House Price) dataset.

Step 1: Import Dependent Packages

We begin by importing the necessary libraries:

  • LinearRegression from sklearn for the model.

  • matplotlib for plotting graphs.

  • numpy for numerical operations.

from sklearn.linear_model import LinearRegression
import matplotlib.pyplot as plt
import numpy as np

Step 2: Build and Visualize the Dataset

We create a small dataset manually where:

  • x represents the House Area (sqm).

  • y represents the House Price ($).

We then create a scatter plot to visualize the relationship.

# House Area (Features)
x = np.array([121, 125, 131, 141, 152, 161]).reshape(-1,1)

# House Price (Labels)
y = np.array([300, 350, 425, 405, 496, 517])

plt.scatter(x,y)
plt.xlabel("Area (sqm)")
plt.ylabel("Price ($)")
plt.title("House Area vs Price")
plt.show()

Step 3: Train the Model

We create an instance of the LinearRegression model and fit it to our data (x, y).

# Initialize and Train
lr = LinearRegression()
lr.fit(x,y)

Step 4: Visualize the Model

Now that the model is trained, we can extract the learned parameters:

  • Slope (w): lr.coef_

  • Intercept (b): lr.intercept_

We then plot the "Best Fit Line" over our original scatter plot to see how well our model fits the data.

w = lr.coef_[0]
b = lr.intercept_
print('Slope (w): ', w)
print('Intercept (b): ', b)

plt.scatter(x,y)
plt.xlabel("Area")
plt.ylabel("Price")

# Plot the regression line
plt.plot([x[0], x[-1]], [x[0]*w+b, x[-1]*w+b], color='red', label='Regression Line')
plt.legend()
plt.show()

Step 5: Make a Prediction

We can now use our trained model to predict the price of a house with a specific area (e.g., 130 sqm).

testX = np.array([[130]])
prediction = lr.predict(testX)
print(f"Predicted price for area 130 sqm: ${prediction[0]:.2f}")

Summary

In this lab, you successfully:
1. Prepared Data: Created a simple dataset and reshaped the features for Scikit-Learn.
2. Trained a Model: Used LinearRegression().fit() to find the best-fit line.
3. Visualized Results: Plotted the data points and the regression line to verify the relationship.
4. Made Predictions: Used the trained model to estimate values for new inputs.

Self Reflection

  1. Shape Matters: Why did we have to use .reshape(-1,1) on our x array? What does Scikit-Learn expect?
  2. Model Parameters: Look at the slope (w) printed in Step 4. If this value was negative, what would that imply about House Prices vs Area?
  3. Real World: In reality, is Area the only factor for House Price? How would you modify x to include "Number of Bedrooms"?
