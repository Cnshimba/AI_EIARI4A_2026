1. What is Machine Learning?

Tom Mitchell's Definition

A computer program is said to learn from experience $E$ with respect to some task $T$ and performance measure $P$, if its performance on $T$, as measured by $P$, improves with experience $E$.

Traditional vs. Machine Learning

Traditional Programming:

  • You write the rules

  • Data + Rules → Answers

Machine Learning:

  • The computer learns the rules

  • Data + Answers → Rules

2. Types of Learning

Supervised Learning

  • Data: Input ($X$) + Correct Output ($Y$)

  • Goal: Learn mapping $X \to Y$

  • Tasks:

  • Regression: Predict continuous values (prices, temperatures)

  • Classification: Predict categories (spam/not spam, cat/dog)

Unsupervised Learning

  • Data: Input ($X$) only, no labels

  • Goal: Find hidden structure or patterns

  • Tasks: Clustering, dimensionality reduction

Reinforcement Learning

  • Data: Rewards & penalties from environment

  • Goal: Maximize cumulative reward

  • Example: Game playing, robotics

Section 1: Linear Regression

3. Linear Regression: The Basics

Goal

Predict a continuous value from input features

Example: Predict house price from area

The Equation

$$y = wx + b$$

Where:

  • $y$ = predicted output

  • $x$ = input feature (e.g., house area)

  • $w$ = weight (slope)

  • $b$ = bias (intercept)

4. How Do We Learn?

The Loss Function: Mean Squared Error (MSE)

How do we measure our prediction error?

$$\text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_{\text{pred}} - y_{\text{true}})^2$$

Goal: Minimize this error!

Gradient Descent

The Optimizer: Algorithm to find the best $w$ and $b$

Analogy: Walking down a foggy mountain

  1. Look for the steepest descent
  2. Take a step (controlled by learning rate $\alpha$)
  3. Repeat until you reach the bottom

  • Gradient Descent: Optimization algorithm to minimize loss

Section 2: Classification

6. Regression vs. Classification

Key Difference

Regression:

  • Output: Continuous number

  • Examples: $300k, $452k (house prices), 23.5°C (temperature)

Classification:

  • Output: Discrete category/label

  • Examples: Spam/Not Spam (0/1), Cat/Dog/Bird (0/1/2)

7. Logistic Regression

Concept

Despite the name, it's a classification algorithm!

Uses a linear equation to separate classes: $z = wx + b$

But transforms it with the sigmoid function: $g(z) = \frac{1}{1 + e^{-z}}$

Why Sigmoid?

  • Converts any number into a probability between 0 and 1

  • Decision rule: If $g(z) > 0.5$ → Predict Class 1; If $g(z) < 0.5$ → Predict Class 0

Decision Boundary

The line/surface where $g(z) = 0.5$ separates the two classes

8. Decision Trees

Concept

A flowchart-like structure for making decisions

Think of it like a game of "20 Questions":

  • Ask a series of yes/no questions

  • Each answer narrows down the possibilities

  • Reach a final classification

Key Concepts

Entropy: Measure of impurity/randomness

  • Formula: $H(S) = -\sum p_i \log_2(p_i)$

  • Low entropy = pure (all same class)

  • High entropy = mixed classes

Information Gain: Which question reduces entropy the most?

  • The algorithm picks the question with highest information gain at each step

Advantages

  • Highly interpretable: You can visualize and understand the rules

  • Handles categorical data: No need for encoding like Logistic Regression

Section 2 Checkpoint

Summary

  • Classification: Predicting categories, not numbers

  • Logistic Regression: Linear boundary + sigmoid activation

  • Decision Trees: Rule-based, highly interpretable

Reflection

  • Why can't we use Linear Regression for classification?

  • When would you choose Decision Trees over Logistic Regression?
