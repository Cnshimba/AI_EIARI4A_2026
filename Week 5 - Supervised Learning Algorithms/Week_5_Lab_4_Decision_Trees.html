Foreword

This lab introduces **Decision Trees**, which behave like the "20 Questions" game. You will learn how the model calculates **Entropy** to decide which questions to ask.

Terminology Alert:
Entropy measures "messiness" or uncertainty. A Decision Tree tries to reduce entropy with every split.

Phase 2: Preprocessing (Label Encoding)

Because Scikit-Learn only understands numbers, we use the LabelEncoder to convert text categories like "Sunny" and "Rain" into integers.

from sklearn.preprocessing import LabelEncoder

le = LabelEncoder()
df_encoded = df.apply(le.fit_transform)

Phase 3 & 4: Assembly & Training

We specify criterion='entropy' during assembly to ensure the model uses Information Gain logic.

from sklearn import tree

clf = tree.DecisionTreeClassifier(criterion='entropy')
clf.fit(X, y)

Phase 5: Evaluation (Visualization)

Decision Trees are unique because they are "White Box" models — you can see exactly how the logic works.

import matplotlib.pyplot as plt
tree.plot_tree(clf, filled=True)

Summary

In this lab, you used statistical "messiness" (Entropy) to build a logical flowchart that can predict outcomes like a human.

Step 1: Import Dependencies & Load Data

We need pandas for data handling and DecisionTreeClassifier from sklearn.

The data is stored in tennis.txt.

import pandas as pd
import numpy as np
from sklearn import tree
from sklearn.preprocessing import LabelEncoder

# Load dataset
def load_data():
    # Example format of tennis.txt columns: Outlook, Temp, Humidity, Wind, Play
    try:
        data = pd.read_csv('tennis.txt', sep='\t') 
        return data
    except:
        print("Dataset not found. Creating manual dataset.")
        # Fallback dictionary if file missing
        d = {
            'Outlook': ['Sunny','Sunny','Overcast','Rain','Rain','Rain','Overcast','Sunny','Sunny','Rain','Sunny','Overcast','Overcast','Rain'],
            'Temp': ['Hot','Hot','Hot','Mild','Cool','Cool','Cool','Mild','Cool','Mild','Mild','Mild','Hot','Mild'],
            'Humidity': ['High','High','High','High','Normal','Normal','Normal','High','Normal','Normal','Normal','High','Normal','High'],
            'Wind': ['Weak','Strong','Weak','Weak','Weak','Strong','Strong','Weak','Weak','Weak','Strong','Strong','Weak','Strong'],
            'Play': ['No','No','Yes','Yes','Yes','No','Yes','No','Yes','Yes','Yes','Yes','Yes','No']
        }
        return pd.DataFrame(d)

data = load_data()
print(data.head())

Step 2: Preprocess Data (Encoding)

Decision Trees in sklearn (feature vectors) require numerical input. Our data involves strings ("Sunny", "Hot").
We use LabelEncoder to convert these text categories into numbers (e.g., Sunny=0, Rain=1).

# Initialize Encoders for each column
le_outlook = LabelEncoder()
le_temp = LabelEncoder()
le_humidity = LabelEncoder()
le_wind = LabelEncoder()
le_play = LabelEncoder()

# Apply Encoding
data_encoded = data.copy()
data_encoded['Outlook'] = le_outlook.fit_transform(data['Outlook'])
data_encoded['Temp'] = le_temp.fit_transform(data['Temp'])
data_encoded['Humidity'] = le_humidity.fit_transform(data['Humidity'])
data_encoded['Wind'] = le_wind.fit_transform(data['Wind'])
data_encoded['Play'] = le_play.fit_transform(data['Play'])

print("\nEncoded Data:")
print(data_encoded.head())

Step 3: Train the Model

We split the data into Features (X) and Labels (y) and train the tree.
We use Entropy as the criterion for splitting nodes.

# Features (First 4 columns)
X_train = data_encoded.iloc[:, :-1]

# Labels (Last column)
y_train = data_encoded.iloc[:, -1]

# Initialize Decision Tree with Entropy
clf = tree.DecisionTreeClassifier(criterion='entropy')

# Train
clf.fit(X_train, y_train)
print("Decision Tree Trained!")

Step 4: Visualize the Tree

We can visualize exactly how the tree makes decisions.

import graphviz 

# Define class names and feature names for the graph
feature_names = ['Outlook', 'Temp', 'Humidity', 'Wind']
class_names = ['No', 'Yes']

# Export tree as data
dot_data = tree.export_graphviz(clf, out_file=None, 
                                feature_names=feature_names,  
                                class_names=class_names,
                                filled=True, rounded=True,  
                                special_characters=True)  

# Render graph
graph = graphviz.Source(dot_data) 
# graph.render("tennis_tree") # Saves PDF if needed
graph

(Note: To view the graph, you need graphviz installed on your system. If not, the code usually displays the Graphviz object in Jupyter Notebooks)

Step 5: Prediction

Lets predict:

  • Outlook: Sunny

  • Temp: Cool

  • Humidity: High

  • Wind: Strong

# Transform inputs using the same label encoders
# Note: This requires the encoders to have seen these values during fit
try:
    input_vector = [
        le_outlook.transform(['Sunny'])[0],
        le_temp.transform(['Cool'])[0],
        le_humidity.transform(['High'])[0],
        le_wind.transform(['Strong'])[0]
    ]

    prediction = clf.predict([input_vector])
    result = le_play.inverse_transform(prediction)[0]

    print(f"Prediction for (Sunny, Cool, High, Strong): {result}")
except Exception as e:
    print(f"Error in prediction encoding: {e}")

Summary

In this final lab, you built a Decision Tree:

2. Entropy: Used the entropy criterion to let the tree decide the best questions to ask at each split.
3. Visualization: Generated a flowchart of the model's decision-making process.
