Foreword

This lab introduces Random Forest, a powerful ensemble learning algorithm. You will learn the "Wisdom of the Crowd" concept and see why forest models are more robust than single decision trees.

Assembly Power:
Random Forest doesn't rely on one "expert" tree. It asks 100+ "average" trees and takes the average/majority vote. This prevents errors from outliers!

Phase 2 & 3: Preprocessing & Assembly

We use a Pipeline to ensure our data matches the scale requirements of the model every time we run it.

from sklearn.ensemble import RandomForestClassifier
from sklearn.pipeline import Pipeline

pipeline = Pipeline([
    ('scaler', StandardScaler()),
    ('classifier', RandomForestClassifier(n_estimators=100))
])

Phase 4: Training (The Forest Grows)

When you call .fit(), Scikit-Learn builds dozens of unique trees. Each tree only sees a slice of the data (Bagging) and a slice of the features (Feature Randomness).

pipeline.fit(X_train, y_train)

Phase 6: Optimization (Feature Importance)

Random Forests allow us to see which features contributed most to the prediction. This is known as Feature Importance.

# Get importances from the classifier step
importances = pipeline.named_steps['classifier'].feature_importances_

Summary

In this lab, you used the **Wisdom of the Crowd** to build a highly accurate classifier that is far more stable than a single Decision Tree.
