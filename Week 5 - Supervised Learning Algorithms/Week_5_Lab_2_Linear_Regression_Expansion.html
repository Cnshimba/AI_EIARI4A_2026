Lab Goal: Gradient Descent from Scratch
In this lab, we dive deeper by implementing the math behind Linear Regression manually using numpy. This gives you a clear understanding of how the model "learns" using Gradient Descent.

We will use the dataset lr2_data.txt.

Step 1: Import Dependencies

import numpy as np
import matplotlib.pyplot as plt

Step 2: Define Gradient Calculation Function

The core of learning is calculating the Gradient (direction of steepest ascent). We want to move in the opposite direction (descent) to minimize error.

The formula for the gradient is:
$$ \frac{\partial J}{\partial \theta} = \frac{1}{m} X^T (X\theta - y) $$

def generate_gradient(X, theta, y):
    sample_count = X.shape[0]
    # Calculate gradient using matrix multiplication
    return (1./sample_count) * X.T.dot(X.dot(theta) - y)

Step 3: Define Data Loading Function

This helper function reads the lr2_data.txt file and splits it into Features (X) and Labels (y).

def get_training_data(file_path):
    try:
        orig_data = np.loadtxt(file_path)
        cols = orig_data.shape[1]
        # Last column is y, previous columns are X
        return (orig_data, orig_data[:, :cols - 1], orig_data[:, cols-1:])
    except Exception as e:
        print(f"Error reading data: {e}")
        return None

Step 4: Initialize Parameters

We need to start our weights ($\theta$) somewhere. We initialize them to 1.

def init_theta(feature_count):
    return np.ones(feature_count).reshape(feature_count, 1)

Step 5: Implement Gradient Descent Loop

This is the training loop:
1. Calculate current Loss ($J(\theta)$).
2. Calculate Gradient.
3. Update $\theta$ using Learning Rate $\alpha$:
$$ \theta := \theta - \alpha \times \text{gradient} $$
4. Repeat until convergence (gradient becomes very small).

def gradient_descending(X, y, theta, alpha):
    Jthetas= []

    # Calculate Initial Loss
    Jtheta = (X.dot(theta)-y).T.dot(X.dot(theta)-y)
    index = 0
    gradient = generate_gradient(X, theta, y)

    # Loop until gradient is close to zero
    while not np.all(np.absolute(gradient) <= 1e-5):
        theta = theta - alpha * gradient
        gradient = generate_gradient(X, theta, y)
        Jtheta = (X.dot(theta)-y).T.dot(X.dot(theta)-y)

        if (index+1) % 10 == 0:
            Jthetas.append((index, Jtheta[0][0]))

        index += 1
        if index > 10000: break # Safety break

    return theta, Jthetas

Step 6: Visualization Helpers

We define functions to plot the Loss Curve (to ensure the model is learning) and the final Regression Line.

def showJTheta(diff_value):
    p_x = []
    p_y = []
    for (index, sum) in diff_value:
        p_x.append(index)
        p_y.append(sum)
    plt.plot(p_x, p_y, color='b')
    plt.xlabel('Steps')
    plt.ylabel('Loss Function')
    plt.title('Step vs Loss Function Curve')
    plt.show()

def showlinercurve(theta, sample_training_set):
    x, y = sample_training_set[:, 0], sample_training_set[:, 1]
    z = theta[0] + theta[1] * x
    plt.scatter(x, y, color='b', marker='x', label="Data Points")
    plt.plot(x, z, 'r', color="r", label="Regression Curve")
    plt.xlabel('x')
    plt.ylabel('y')
    plt.title('Linear Regression Fit')
    plt.legend()
    plt.show()

Step 7: Execution

Now we run our manual implementation.
Note: We add a column of 1s to our Feature Matrix X. This is the "Bias Trick" to handle the Intercept term.

# 1. Read Data
data_path = "lr2_data.txt"
# Assuming you have the file, otherwise create dummy data:
# training_data_include_y = np.array([[1, 2], [2, 4], [3, 6]])
# training_x = training_data_include_y[:, 0]
# y = training_data_include_y[:, 1]

training_data_include_y, training_x, y = get_training_data(data_path)

if training_data_include_y is not None:
    # 2. Prepare Data (Add Bias Term)
    m = len(training_x)
    x0 = np.ones((m, 1))
    training_x_biased = np.hstack((x0, training_x.reshape(-1, 1)))

    # 3. Setup Hyperparameters
    sample_count, feature_count = training_x_biased.shape
    alpha = 0.0000001 # Learning Rate

    # 4. Train
    theta = init_theta(feature_count)
    result_theta, Jthetas = gradient_descending(training_x_biased, y.reshape(-1,1), theta, alpha)

    # 5. Results
    print("w (Bias): {}".format(result_theta[0][0]))
    print("w (Slope): {}".format(result_theta[1][0]))

    showJTheta(Jthetas)
    showlinercurve(result_theta, training_data_include_y)
else:
    print("Data file not found. Ensure lr2_data.txt is in the same directory.")

Summary

In this expansion lab, you looked under the hood of machine learning:
1. The Math: You implemented the cost function $J(\theta)$ and gradient calculations manually.
2. The Loop: You built the training loop that iteratively updates weights using $\theta := \theta - \alpha \nabla J$.
3. Visualization: You observed how the Loss decreases over time, confirming the model is "learning."

Self Reflection

  1. Learning Rate: What happens if you change alpha to 0.1? Or 0.000000001? Try it and observe the Loss Curve.
  2. Convergence: The loop stops when the gradient is small (<= 1e-5). Why don't we just run it for a fixed 1,000,000 steps every time?
  3. The Bias Trick: We added a column of 1s to X. Why is this mathematical trick necessary for the "Intercept" ($b$)?
