Part 1: The MediaPipe Architecture

While models like YOLO detect where an object is (a bounding box), models like MediaPipe Hands detect the exact structural skeleton of the object. It outputs exactly 21 3D coordinates (landmarks) mapping every joint in the human hand. Because it is highly optimized, it runs at 30+ FPS even on basic CPUs like the Raspberry Pi.

Part 2: Live Landmark Tracking

Let's open the webcam and draw the 21 hand landmarks. This script initializes the MediaPipe Hands solution and overlays the connections directly onto your video feed.

import cv2
import mediapipe as mp

mp_drawing = mp.solutions.drawing_utils
mp_hands = mp.solutions.hands

cap = cv2.VideoCapture(0)

# Initialize the Hands model
with mp_hands.Hands(min_detection_confidence=0.7, min_tracking_confidence=0.7) as hands:
    while cap.isOpened():
        success, image = cap.read()
        if not success:
            break

        # Convert colors from BGR (OpenCV) to RGB (MediaPipe)
        image = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)
        results = hands.process(image)
        
        # Convert back to BGR for rendering
        image = cv2.cvtColor(image, cv2.COLOR_RGB2BGR)

        # Draw the hand annotations on the image
        if results.multi_hand_landmarks:
            for hand_landmarks in results.multi_hand_landmarks:
                mp_drawing.draw_landmarks(
                    image, hand_landmarks, mp_hands.HAND_CONNECTIONS)

        cv2.imshow('MediaPipe Hand Tracking', image)
        
        if cv2.waitKey(1) & 0xFF == ord('q'):
            break

cap.release()
cv2.destroyAllWindows()

Part 3: From Vision to Kinematic Control

Drawing lines is visually satisfying, but it does not control a robot. To issue a command, we must translate these coordinates into kinematic logic. We do this by calculating the relative distances between joints.

For example, to detect an "Open Hand" vs a "Closed Fist", we can measure the distance between the fingertip (Landmark 8) and the wrist (Landmark 0).

3.1 The Gesture Logic Script

Replace your inner loop with the following code to implement basic gesture control. This logic triggers a simulated "System Action" when specific spatial conditions are met.

        if results.multi_hand_landmarks:
            for hand_landmarks in results.multi_hand_landmarks:
                
                # Extract specific landmarks (Y coordinates are normalized 0.0 to 1.0)
                wrist_y = hand_landmarks.landmark[0].y
                index_tip_y = hand_landmarks.landmark[8].y
                middle_tip_y = hand_landmarks.landmark[12].y
                
                # Logic: Is the index finger fully extended while the middle finger is down?
                # (Remember: Y=0 is the top of the screen, Y=1 is the bottom)
                if index_tip_y < wrist_y - 0.3 and middle_tip_y > wrist_y - 0.1:
                    cv2.putText(image, "COMMAND: DRONE ASCEND", (50, 50), 
                                cv2.FONT_HERSHEY_SIMPLEX, 1, (0, 255, 0), 2)
                    print("[SYSTEM] Executing ASCEND command via UDP...")
                
                # Logic: Are all fingers curled in (Fist)?
                elif index_tip_y > wrist_y - 0.15 and middle_tip_y > wrist_y - 0.15:
                    cv2.putText(image, "COMMAND: EMERGENCY STOP", (50, 50), 
                                cv2.FONT_HERSHEY_SIMPLEX, 1, (0, 0, 255), 2)
                    print("[SYSTEM] Executing BRAKE / STOP...")

                mp_drawing.draw_landmarks(image, hand_landmarks, mp_hands.HAND_CONNECTIONS)

System Engineering Insight: This is exactly how commercial quadcopters (like DJI drones) interpret "Follow Me" or "Take Photo" gestures. The vision system acts as a sensor, providing structured JSON coordinate data to the flight controller over an internal serial bus.
