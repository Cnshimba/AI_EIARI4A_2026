Lab 2: Building Your AI Pair Programmer

Integration of local LLMs into the developer workflow.

Goal

Connect your local Ollama instance to **VS Code** to create a free, private, and offline alternative to GitHub Copilot.

Part 1: Setup Continue

Continue is an open-source extension for VS Code that allows you to use any LLM for code autocomplete and chat.

  1. Open VS Code.
  2. Go to the Extensions tab (Ctrl+Shift+X).
  3. Search for "Continue" and install it.

Part 2: Configuring the Local Provider

We need to tell Continue to talk to our local Ollama server instead of a cloud API.

  1. Click the Continue icon in the sidebar.
  2. Click the gear icon (config) at the bottom.
  3. Paste the following configuration into the models section:
{
  "title": "Local Phi-3",
  "model": "phi3:mini",
  "provider": "ollama"
}

Part 3: Testing the Offline Assistant

Turn off your Wi-Fi. This is the ultimate test of localized AI.

  1. Highlight some code in a Python file.
  2. Press Ctrl + I (Inline Edit) or Ctrl + L (Chat).
  3. Ask: "Add comments to this function and optimize the loops."

The model running on your laptop/Pi 5 should generate the response immediately without any internet connection.
