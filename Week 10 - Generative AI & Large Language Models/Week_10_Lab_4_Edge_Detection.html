Lab 4: Live Edge Detection

Real-time Computer Vision with YOLOv8
Lab Goal
Use a pre-trained YOLOv8 (You Only Look Once) model to perform real-time object detection on a live video stream. You will compare performance on CPU vs GPU and explore the "Nano" version of the architecture.

Part 1: The YOLO Architecture

Unlike traditional classifiers that look at an image multiple times, **YOLO** treats detection as a single regression problem, straight from pixels to bounding box coordinates and class probabilities. We will use the Nano (n) version, which is optimized for edge devices like the Raspberry Pi and Jetson Nano.

Part 2: Live Detection Script

This script opens your webcam, feeds each frame into the YOLOv8 model, and draws bounding boxes around detected objects in real-time.

from ultralytics import YOLO
import cv2

# Load the nano model (very lightweight)
model = YOLO('yolov8n.pt') 

# Open webcam (0 is default)
cap = cv2.VideoCapture(0)

while cap.isOpened():
    success, frame = cap.read()
    if not success:
        break

    # Run inference on the frame
    results = model(frame, stream=True)

    # Visualize the results on the frame
    for r in results:
        annotated_frame = r.plot()

    # Display the resulting frame
    cv2.imshow("YOLOv8 Edge Detection", annotated_frame)

    # Break loop on 'q' press
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()

Part 3: Performance Analysis

While the script is running, observe the console output. You will see time measurements (e.g., 15.0ms preprocess, 100.2ms inference).

Hardware Expected Inference Time Smoothness
High-end Laptop (GPU) ~5ms - 15ms Very Smooth (30+ FPS)
Standard Laptop (CPU) ~50ms - 150ms Choppy (5-10 FPS)
Raspberry Pi 5 (CPU) ~100ms - 200ms Laggy (3-5 FPS)
Jetson Nano (CUDA) ~20ms - 40ms Usable (15-25 FPS)

Observation: Note how the Nano model allows real-time interaction even on non-specialized hardware, whereas larger models (like YOLOv8x) would be too slow.
