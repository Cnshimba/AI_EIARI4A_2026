Lab 1: Universal SLM Deployment

Localized AI on Raspberry Pi & Laptops

Goal

Deploy a Small Language Model (SLM) locally using Ollama. You will measure the performance differences between different hardware tiers (Laptop CPU vs Raspberry Pi 5 vs VM).

Part 1: Setting up Ollama

Ollama is the standard tool for running quantized models locally. It abstracts the complexity of llama.cpp.

1.1 Installation

  • Windows/Mac: Download the installer from ollama.com.
  • Linux / Raspberry Pi 5: Run this command in your terminal: 
    curl -fsSL https://ollama.com/install.sh | sh

Part 2: Selecting & Running an SLM

We will use Phi-3 Mini (3.8B parameters) or Phi-2 (2.7B parameters). These models are small enough to run on a Pi 5 or a basic laptop while remaining highly capable.

2.1 Run the Model

# This will download and start the model
ollama run phi3:mini

2.2 Benchmark Performance

Ask the model a complex question like: "Explain the relationship between the Fourier Transform and Signal Processing in 4 paragraphs."

Note the speed: Look at the output. Does it feel "instant" or "gradual"?

  • Laptop (i7/M1+): Should achieve ~20-50 tokens/sec.
  • Raspberry Pi 5 (8GB): Should achieve ~3-7 tokens/sec.

Part 3: The API Protocol

Ollama runs a local server at port 11434. You can talk to it via simple HTTP requests.

3.1 Python Script (The Edge Agent)

import requests

def talk_to_local_ai(prompt):
    url = "http://localhost:11434/api/generate"
    data = {
        "model": "phi3:mini",
        "prompt": prompt,
        "stream": False
    }
    response = requests.post(url, json=data)
    return response.json()['response']

print(talk_to_local_ai("What is the capital of South Africa?"))
