Lab 6: Local Voice Assistant

Chaining Whisper + Ollama on Edge Hardware
Lab Goal
Ollama is strictly designed for Text and Vision models, meaning it cannot natively "hear" audio. To build a voice assistant, we must architect a pipeline. In this lab, we will capture your microphone, use OpenAI's open-source Whisper model to transcribe the speech offline, and feed that text into Ollama to generate a smart response.

Part 1: The Voice Architecture

Modern AI systems rarely rely on a single monolithic model. A state-of-the-art voice assistant relies on three distinct AI engines working in sequence:

  1. Acoustic Model (Local): Turns audio waves into Words (Whisper).
  2. Language Model (Local): Reads the words and generates a logical textual reply (Phi-3 via Ollama).
  3. TTS Model (Optional): Turns the reply back into audio waves (e.g., Pyttsx3 / Coqui).

Part 2: The Whisper-Ollama Pipeline

Create a file named voice_assistant.py. We will configure it to listen to your default microphone. Once you stop speaking, it passes the audio to Whisper. Whisper's output is then immediately requested via the Ollama python API.

import speech_recognition as sr
import whisper
import requests
import json
import warnings

# Suppress PyTorch warnings
warnings.filterwarnings("ignore", category=UserWarning)

print("Loading Whisper 'base' model... (This runs 100% offline)")
# 'base' and 'tiny' run incredibly fast even on CPU or Jetson Nano
model = whisper.load_model("base")
recognizer = sr.Recognizer()

# Ensure Ollama is running in the background (e.g., phi3 or llama3)
OLLAMA_API = "http://localhost:11434/api/generate"
OLLAMA_MODEL = "phi3" 

def ask_ollama(prompt_text):
    print(f"\n[Ollama] Thinking...", end="", flush=True)
    payload = {
        "model": OLLAMA_MODEL,
        "prompt": prompt_text,
        "stream": False
    }
    try:
        response = requests.post(OLLAMA_API, json=payload)
        response_text = response.json()["response"]
        print(f"\r[Ollama response]:\n{response_text}\n")
    except Exception as e:
        print("\n\n[ERROR] Is Ollama running? Run: ollama serve")

print("Initializing Microphone...")
with sr.Microphone() as source:
    recognizer.adjust_for_ambient_noise(source)
    print("Ready! Say something...")
    
    while True:
        try:
            # Listen to the user
            audio = recognizer.listen(source)
            print("\n[Whisper] Transcribing audio...")
            
            # Save temporary wav buffer
            with open("temp.wav", "wb") as f:
                f.write(audio.get_wav_data())
            
            # Transcribe via Whisper
            result = model.transcribe("temp.wav")
            transcription = result["text"].strip()
            print(f"[You said]: {transcription}")
            
            if transcription:
                # Pipe transcription to LLM Foundation Model
                ask_ollama(transcription)

        except KeyboardInterrupt:
            print("\nShutting down assistant.")
            break
        except Exception as e:
            print(f"Error: {e}")

System Engineering Insight: Notice how fast this is on a modern laptop? Real-time translation used to require massive server farms. By using a SLM (Small Language Model) for intelligence and a heavily quantized Acoustic Model (Whisper base), you've created a zero-latency, zero-cost, 100% private Siri/Alexa alternative.
