3. The Transformer Revolution

Before 2017, we used RNNs (processed word-by-word, slow).
Then came Attention Is All You Need (Google, 2017).

  • Key Idea: "Attention." The model looks at the entire sentence at once.

  • Mechanism: Self-Attention allows each word to "vote" on which other words are relevant to it.

  • Result: Massive parallelization $\rightarrow$ Massive models (GPT).

4. How LLMs are Made

It's a two-step process:

  1. Pre-Training: The "Library Phase."

  • Task: Predict the next word.

  • Data: Trillions of tokens (Internet).

  • Result: A model that knows English/Code but acts like an autocomplete.
    2. Fine-Tuning / Alignment: The "School Phase."

  • Task: Follow Method/Chat.

  • Data: Quality Q&A pairs.

  • Result: ChatGPT / Llama / Claude.

5. Checkpoint 1

Token Prediction

If I give the model: "The capital of France is ..."
Why does it say "Paris"?

Click for Answer It's not "looking up facts." It's calculating probabilities. In its training data, "Paris" is statistically the most likely token to follow that sequence.

6. Running LLMs Locally

"But don't I need an H100 GPU?"
Not anymore. Enter Quantization.

  • FP16 (16-bit): Standard training precision. Massive RAM usage.

  • INT4 (4-bit): Quantized inference. slightly lower accuracy, 4x smaller.

  • GGUF: The file format we use to run Llama-3-8B on a CPU.

9. Summary

  • Transformers: Replaced RNNs by using Attention (Parallelizable).

  • Pre-training: Teaches language structure (Autocomplete).

  • Alignment: Teaches helpfulness (Chatbot).

  • Quantization: Allows us to run massive 8B+ parameter models on consumer hardware.
