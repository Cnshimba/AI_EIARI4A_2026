Week 4: Machine Learning Foundations

1. Learning Outcomes

By the end of this session, you will be able to:
1. Differentiate between Traditional Programming and Machine Learning.
2. Classify problems as Supervised (Regression/Classification) or Unsupervised (Clustering).
3. Implement the 3-Step Scikit-Learn Pattern (Instantiate, Fit, Predict).
4. Split data into Training and Testing sets significantly.
5. Diagnose Overfitting vs Underfitting.

Week Goal: Transition from "Writing Rules" to "Teaching Machines."

2. The Paradigm Shift

Programming vs Learning

  • Traditional Programming: You give the Rules and Data -> Computer gives Answers.

  • Example: Calculate tax (we know the formula).

  • Machine Learning: You give the Data and Answers -> Computer figures out the Rules.

  • Example: Recognize a face (we don't know the math formula for a "nose").

Key Insight: We don't code the solution. We code the pipeline that finds the solution.

3. Taxonomy of Machine Learning

3.1 Supervised Learning (The Teacher)

  • Definition: The model learns from "Labeled Data" (Input + Correct Answer).

  • Types:

  • Regression: Predict a number (e.g., House Price).

  • Classification: Predict a category (e.g., Spam vs Not Spam).

3.2 Unsupervised Learning (The Explorer)

  • Definition: The model looks for patterns in "Unlabeled Data" (Input only).

  • Types:

  • Clustering: Grouping similar items (e.g., Customer Segmentation).

  • Dimensionality Reduction: Simplifying complex data.

4. The Engineering Workflow

4.1 The Golden Rule: Train/Test Split

  • Problem: Models love to "memorize" (cheat).

  • Solution: Hide data from the model.

  • Training Set (80%): The Homework (Model learns from this).

  • Test Set (20%): The Final Exam (Model is evaluated on this).

4.2 Scikit-Learn Pattern

The industry standard library sklearn uses a consistent 3-step process:
1. Instantiate: model = LinearRegression()
2. Fit: model.fit(X_train, y_train) (The Learning)
3. Predict: model.predict(X_test) (The Application)

5. How Learning Happens (Internals)

Components of a Model

  1. Weights: How important an input is (Multipliers).
  2. Biases: Baseline adjustments (Addition).
  3. Loss Function: The "Score" (Measure of error).
  4. Gradient Descent: The "Hike" (Adjusting weights to lower the error).
Learning is simply finding the specific Weights and Biases that minimize the Loss Function.

6. Generalization

Overfitting vs Underfitting

  • Underfitting (High Bias): Model is too stupid.

  • Analogy: Using a straight ruler on a race track.

  • Fix: Make model more complex.

  • Overfitting (High Variance): Model is memorizing noise.

  • Analogy: Memorizing exact exam answers but failing similar questions.

  • Fix: More data, simpler model, or Regularization.

7. Section Checkpoint

  1. Scenario: You want to predict if a credit card transaction is fraudulent. Is this Regression, Classification, or Clustering?
  2. Scenario: You want to group customers by shopping habits. Is this Supervised or Unsupervised?
  3. True/False: We train the model on the Test Set to ensure it is accurate.
Answers 1. **Classification** (Supervised: Fraud/Not Fraud). 2. **Unsupervised** (Clustering: No "correct" answer given). 3. **FALSE**! Never train on the Test Set. That is cheating (Data Leakage).

8. Summary

Concept Description
Paradigm Data + Answers = Rules (Inductive Learning).
Supervised Learning with Labels (Regression/Classification).
Unsupervised Learning without Labels (Clustering).
Workflow Split Data -> Instantiate -> Fit -> Predict.
Goal Generalization (Performance on Unseen Data).
