Option B: Time-Series Forecasting

Project: Predictive Modeling

Goal: Build a sequence model to predict future values based on historical trends, handling patterns like seasonality and trend.

Specific Learning Outcomes
1. Master Data Windowing (creating sequences from continuous data).
2. Implement Recurrent Neural Networks (LSTM or GRU).
3. Evaluate forecasting performance (MAE vs MSE).

1. The Scenario

Forecasting is critical for resource planning. Can you predict the price of Bitcoin next week? Or the energy consumption of a city based on temperature? Or the number of server requests during Black Friday?

2. Tools & Constraints

  • Dataset: Stock Prices (Yahoo Finance), Weather Data, Energy Consumption, Server Logs.
  • Architecture: RNN, LSTM, or GRU in TensorFlow/PyTorch.
  • Constraint: You MUST demonstrate a baseline (e.g., Linear Regression or "Previous Value") comparison to prove your Deep Learning model adds value.

3. Step-by-Step Pipeline

Step 1: Data Preparation (Windowing)

Time series data is sequential. You need to convert it into supervised learning pairs (X, y). 

# Example: Window Size 30
# Input (X): Days 1-30
# Label (y): Day 31

Requirement: Split data chronologically (Train on Past, Test on Future). Do not shuffle randomly!

Step 2: Feature Engineering

  • Scaling: Use MinMaxScaler (LSTM is sensitive to scale).
  • Seasonality: Extract "Day of Week" or "Month" as additional features.
  • Lag Features: Add previous steps as input columns.

Step 3: Model Architecture

Build a Recurrent Network:

  • Layer 1: LSTM or GRU (units=50, return_sequences=True/False).
  • Dropout: Essential to prevent overfitting.
  • Output: Dense(1) (for regression).

Step 4: Training & Evaluation

  • Loss Function: MSE (Mean Squared Error) or MAE.
  • Viz: Plot Actual vs Predicted lines overlapping.
  • Metric: Calculate how far off your predictions are on average (RMSE).

Step 5: Future Projection

Try to predict multiple steps ahead (auto-regressive prediction) and visualize how the error compounds over time.
