Week 12 Project CNN

← Back to Project Overview

Project Goal:
Build and optimize a Convolutional Neural Network (CNN) to classify images into at least 5 distinct categories. You will demonstrate mastery of deep learning architectures, data augmentation, and model interpretability.

1. The Scenario

Choose a real-world visual problem. Examples include:

  • Identifying crop diseases from leaf photos.

  • Classifying traffic signs for autonomous systems.

  • Detecting fractures in medical X-ray imaging.

  • Identifying waste types for smart recycling bins.

Your model must be robust enough to handle variations in the input data (lighting, angles, scale).

2. Learning Outcomes

  1. Implement Data Augmentation to solve overfitting.
  2. Design deep ConvNet architectures (filters, pooling, dropout).
  3. Visualize intermediate layer activations (Explainable AI).
  4. Evaluate model performance using multi-class metrics.

3. Tools & Constraints

Mandatory Tools

  • Framework: TensorFlow (Keras) or PyTorch.

  • Dataset: You must find a suitable dataset (Kaggle, Google Dataset Search). Minimum 5 classes, minimum 500 images per class.

Explicitly NOT Required

❌ Using pre-trained models (Transfer Learning) as your primary submission.

You must build a CNN from scratch first to show you understand the architecture. You can compare against Transfer Learning for extra credit.

4. Project Structure (Graded Pipeline)

Part A: Data Preprocessing & Augmentation (20%)

Raw images are rarely perfect. You must implement specific augmentations:

  • Implement rotation, zoom, horizontal flips, and rescaling.

  • Requirement: Visualize the augmented images in your notebook to prove they are diverse but representative.

Part B: Architecture Design (25%)

Build a CNN with at least:

  • 3 Convolutional Blocks (Conv2D + ReLU + MaxPooling).

  • Flatten Layer.

  • Dense (Fully Connected) Layers.

  • Dropout (to prevent overfitting).

Part C: Training & Tuning (20%)

Monitor Training vs Validation Loss. You must explicitly discuss how you handled overfitting if it occurred (e.g., adjusting Dropout, L2 Regularization, or Augmentation intensity).

Part D: Explainability & Interpretability (20%)

Deep Learning models should not be black boxes.

  • Visualizing Filters: Show what patterns the first Conv layer is detecting (edges, textures).

  • Activation Maps: Pass a test image and show the feature map output of a late-stage Convolutional layer.

Part E: Evaluation & Error Analysis (15%)

  • Confusion Matrix (identify which classes get confused and why).

  • Show "Most Confused" images.

5. Hardware Track: Edge Vision Deployment (Optional)

If you have an NVIDIA Jetson Orin Nano or a Raspberry Pi with a Camera Module, you can take your project to the next level by deploying your classifier as a real-time vision appliance.

See the dedicated Edge AI Deployment Guide for technical setup, model optimization (TensorRT/TFLite), and camera-interfacing (OpenCV) instructions.
