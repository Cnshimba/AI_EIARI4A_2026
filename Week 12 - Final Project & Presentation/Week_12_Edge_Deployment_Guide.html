Week 12 Edge Deployment Guide

1. Overview

Edge AI allows you to move your Intrusion Detection System from a batch-processing notebook to a real-time network appliance. This guide covers deployment on two popular platforms: the NVIDIA Jetson Orin Nano and the Raspberry Pi.

2. Platform Comparison

Feature NVIDIA Jetson Orin Nano Raspberry Pi (4/5)
Primary Processor 6-core ARM v8.2 4-core ARM v8 (Pi 4) / v8.2 (Pi 5)
AI Acceleration 1024-core Ampere GPU CPU-only (with NEON optimization)
Max Throughput High (GBps-level processing) Medium (MBps-level processing)
Library Focus TensorRT, CUDA TensorFlow Lite, OpenVINO
Vision Potential Real-time 4K / Multi-stream Real-time 1080p / Single stream
Best For Heavy DL / Complex Vision Portable Probes / Edge Classification

3. Computer Vision Track (Jetson & Pi + Camera)

Technical Goal

Deploy your trained image classifier to recognize objects in a live video stream from a CSI or USB camera module.

Vision Steps:

  1. Camera Interfacing:

  • Use OpenCV (cv2) to capture frames.

  • Pro Tip: Map the GStreamer pipeline for Jetson CSI cameras for lower latency.
    2. Preprocessing on the Fly:

  • Resize, normalize, and transpose frames in the capture loop before feeding them to the model.
    3. Optimization:

  • Jetson: Use jetson.utils for zero-copy memory between camera and GPU.

  • Raspberry Pi: Use the Camera Serial Interface (CSI) for lower CPU usage compared to USB.
    4. Display: Overlay the predicted class name and confidence score on the video frame using cv2.putText().

4. Cybersecurity IDS Track (Jetson & Pi + Network)

Technical Goal

Use the hardware-specific TensorRT library to compile your model for maximum performance.

IDS Steps:

  1. Export: Convert your PyTorch or TensorFlow model to ONNX format.
  2. Optimize: Use the trtexec tool on the Jetson to compile the ONNX model into a .trt engine.
  3. Inference:

  • Use the jetson-inference or tensorrt Python libraries.

  • The GPU handles the 1024+ parallel operations required for deep neural networks.
    4. Real-time Sniffing: Use Scapy in a background thread to capture raw packets, extract flow features, and feed them to the TensorRT engine.

5. Raspberry Pi Specific Optimization (CPU)

Technical Goal

Can a Pi achieve the same? Yes. By using TensorFlow Lite (TFLite), you can perform efficient inference on the Pi's ARM processor.

Pi Optimization Steps:

  1. Quantization: Convert your model to a .tflite format.

  • Tip: Use Int8 Quantization to reduce the model size by 4x and speed up inference by using integer math instead of floating-point.
    2. Optimization: Enable XNNPACK or use the Raspberry Pi AI Kit (if available) for NPU acceleration.
    3. Inference:

  • Use the tflite-runtime library.

  • Even without a GPU, the Pi 5 can process thousands of samples per second using optimized CPU instructions (NEON).

6. Unified Data Pipeline

Regardless of the device or track, your edge script will look like this:

import scapy.all as scapy # For IDS
import cv2 # For Vision
import tflite_runtime.interpreter as tflite # For Pi
# or import tensorrt as trt # For Jetson

7. Conclusion

The Jetson is a powerhouse for complex, high-traffic or high-resolution environments, while the Raspberry Pi is an excellent, accessible choice for portable probes and localized vision tasks. Both allow you to move from "offline analysis" to "active edge intelligence."
