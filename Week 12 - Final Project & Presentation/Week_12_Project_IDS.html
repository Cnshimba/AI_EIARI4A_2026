WEEK 12

Final Project & Presentation

Week 12 Project IDS

← Back to Project Overview
Prerequisite: Midterm Project (ML-based IDS on flow CSV)

Project Goal:
This is it—the culmination of your semester. You will combine your cybersecurity knowledge with your new AI skills to build an End-to-End Intrusion Detection System (IDS). You will take raw network traffic (PCAP), clean it, engineer features, and train a Deep Learning model to hunt for attacks. This mirrors the real-world workflow of a Security Operations Center (SOC) analyst or AI Security Engineer.

1. Big Picture Progression

Students now complete the entire security ML pipeline:

PCAP
 ↓
Traffic Feature Extraction (Zeek / CICFlowMeter)
 ↓
Data Cleaning & Feature Engineering
 ↓
Deep Learning Models (Supervised & Unsupervised)
 ↓
Intrusion Detection Analysis

This closes the loop that started in Week 1.

2. Project Scenario

Your organisation suspects malicious activity on its internal network.

A packet capture (PCAP) was taken at the network gateway.

You are tasked with:

  1. Extracting meaningful features from the PCAP
  2. Preparing the data for Deep Learning
  3. Designing a Deep Learning–based Intrusion Detection System (DL-IDS)
  4. Detecting suspicious network behaviour

This mirrors real SOC and blue-team workflows.

3. Learning Outcomes

  1. Understanding of PCAP structure
  2. Ability to extract flow-level features
  3. Ability to design DL pipelines for security
  4. Understanding of temporal and behavioural attacks
  5. Cybersecurity-driven interpretation of AI results

4. Tools & Constraints

Mandatory Tools

  • Zeek OR CICFlowMeter (feature extraction)

  • Python (NumPy, Pandas, Matplotlib)

  • TensorFlow / PyTorch

Explicitly NOT Required

❌ Writing packet parsers
❌ Deep protocol decoding

Focus is security analytics, not packet engineering.

5. Provided Resources

Students receive:

  • traffic_capture.pcap

  • Optionally: attack_capture.pcap

6. Project Structure (Graded Pipeline)

Part A: Understanding PCAP & Traffic Flows (10%)

Students must explain (Markdown):

  • What a PCAP file contains

  • Difference between packets and flows

  • Why feature extraction is required

Part B: PCAP → Flow Feature Extraction (20%)

This is the core upgrade from the midterm.

  • Use Zeek or CICFlowMeter to convert PCAP to CSV.

  • Explain the features extracted.

Part C: Data Cleaning & Feature Engineering (15%)

  • Handle missing values and duplicates.

  • Create at least one new feature (e.g., bytes per packet).

Part D: Deep Learning Model 1 — Supervised IDS (20%)

  • Build a fully connected neural network (Dense Layers).

  • Classify flows as Benign or Suspicious.

Part E: Deep Learning Model 2 — Autoencoder IDS (20%)

  • Cybersecurity centerpiece: Anomaly detection.

  • Train only on benign traffic to learn "normal" behavior.

  • Use reconstruction error to flag zero-day attacks.

Part F: Evaluation & Security Interpretation (10%)

  • Compare Supervised vs. Unsupervised models.

  • Discuss False Positives/Negatives and Alert Fatigue.

Part G: Reflection & Future Work (5%)

  • Discuss evasion techniques and ethical risks.

7. Deliverables

  1. Jupyter Notebook: Complete pipeline with explanations.
  2. Technical Report: 4–6 page PDF detailing methodology and results.
