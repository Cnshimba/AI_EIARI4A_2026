Option A: Cyber-Security Track

Project: End-to-End Intrusion Detection System

Goal: Build a Deep Learning pipeline to detect network attacks from raw traffic (PCAP).

Specific Learning Outcomes
1. Extract flow features from PCAP using tools like Zeek.
2. Train Supervised models for known attack signatures.
3. Train Autoencoders (Unsupervised) for zero-day anomaly detection.

1. The Scenario

Your SOC team intercepted a suspicious PCAP file at the gateway. Traditional firewalls missed it. Your job is to engineer features from this raw data and train a Neural Network to classify flows as Benign or Malicious, and then build an anomaly detector to find what you might have missed.

2. Tools & Constraints

  • Input Data: traffic_capture.pcap (Raw Packets)
  • Feature Extraction: Zeek (recommended) or CICFlowMeter.
  • Model Framework: TensorFlow (Keras) or PyTorch.
  • Constraint: You may NOT use pre-processed CSV datasets (like NSL-KDD) features directly; you must generate your own from the PCAP.

3. Step-by-Step Pipeline

Step 1: From PCAP to CSV (Feature Extraction)

The first challenge is converting binary packet data into a tabular format suitable for Machine Learning. 

# Example with Zeek
zeek -r traffic.pcap
zeek-cut id.orig_h id.resp_h proto service duration orig_bytes resp_bytes < conn.log > traffic.csv

Requirement: You must extract at least 8 relevant features (e.g., Duration, Bytes In/Out, Packets, Protocol).

Step 2: Data Cleaning & Engineering

  • Handle NaN values (common in flow data).
  • Encode categorical variables (TCP/UDP, HTTP/SSH).
  • Normalize numerical features (MinMax or StandardScaler) — crucial for Neural Networks.

Step 3: Model 1 - Supervised Classifier

Train a standard Feed-Forward Neural Network (Dense Layers) to classify records.

  • Input: Vector of flow features.
  • Hidden Layers: ReLU activation, Dropout for regularization.
  • Output: Sigmoid (Probability of Malicious).

Step 4: Model 2 - Autoencoder (Anomaly Detection)

Train a model only on Benign traffic to learn "normality".

  • Architecture: Encoder compression -> Latent Space -> Decoder reconstruction.
  • Logic: If reconstruction error is High, the traffic is an Anomaly (Attack).
  • Thresholding: Determine a dynamic threshold (e.g., Mean + 2*StdDev).

Step 5: Evaluation

Evaluate both models using:

  • Confusion Matrix
  • Precision, Recall, F1-Score (Accuracy is misleading in security).
  • ROC Curve.
