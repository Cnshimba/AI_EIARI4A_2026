3. The Problem with Dense Networks

Why can't we just use the network from last week?

  • Spatial Loss: Flattening an image destroys the 2D structure (neighbors matter!).

  • Parameter Explosion: A 1000x1000 image into 100 neurons = 100 Million weights.

  • Overfitting: Memorizes training data instead of learning patterns.

4. The Solution: Convolutions

Instead of connecting everything, we scan with a Filter (Kernel).

  • Local Features: Detects edges, lines, corners.

  • Translation Invariance: A cat is a cat, whether it's top-left or bottom-right.

5. Checkpoint 1

Concept Check

If you have a 10x10 image and you slide a 3x3 filter over it (no padding), what is the output size?

Click for Answer **8x8**. Formula: (W - K) + 1 = (10 - 3) + 1 = 8.

6. Pooling Layers

After finding features, we valid Max Pooling.

  • Downsampling: Reduces the image size (usually by half).

  • Abstraction: Keeps the strongest feature, discards noise.

  • Efficiency: Reduces computation by 75%.

7. The LeNet-5 Architecture

The "Hello World" of Computer Vision.

class LeNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.feature_extractor = nn.Sequential(
            nn.Conv2d(1, 6, 5),    # C1
            nn.ReLU(),
            nn.MaxPool2d(2, 2),    # S2
            nn.Conv2d(6, 16, 5),   # C3
            nn.ReLU(),
            nn.MaxPool2d(2, 2)     # S4
        )
        self.classifier = nn.Sequential(
            nn.Linear(16 * 4 * 4, 120),
            nn.Linear(120, 84),
            nn.Linear(84, 10)
        )

8. Checkpoint 2

Shape Check

Click for Answer **256**. (16 * 4 * 4 = 256). The fully connected layer needs exactly this many input neurons.
