WEEK 8

Convolutional Neural Networks (CNNs)

Lecture Notes

Course: Computer Systems Engineering
Module: Artificial Intelligence (AI)
Topic: CNNs with TensorFlow/Keras
Duration: 90 Minutes

Lecture Outline

Part 1: The Why and the Biological Inspiration (20 mins)

1.1 Problems with Fully-Connected Networks

  • Spatial Ignorance: Treats pixels as independent features; loses 2D relationships.
  • Parameter Explosion: 1000×1000 image → 100 hidden neurons = 100 million weights. Impossible to train and prone to overfitting.

1.2 Biological Inspiration: The Visual Cortex

  • Hubel & Wiesel (1950s/60s): Discovered that neurons in the visual cortex respond to small, local regions of the visual field (Local Receptive Fields).
  • Hierarchical Processing: Simple cells detect edges $\to$ Complex cells detect patterns $\to$ Hyper-complex cells detect objects.
  • CNN Architecture: Directly mimics this by using small sliding filters instead of global connections.

Part 2: CNN Mechanics — Filters, Padding, and Stride (20 mins)

2.1 The Convolution Operation

  • Slide a small window (Filter/Kernel) across the image.
  • Weights represent patterns (e.g., vertical vs. horizontal lines).
  • Outputs a Feature Map.

2.2 Controlling Dimensions: Stride and Padding

  • Stride ($S$): How many pixels the filter moves per step. High stride = smaller output.
  • Padding ($P$):
    • VALID: No padding; input shrinks.
    • SAME: Zero-padding added to border so output size matches input.

2.3 Pooling Layer (Downsampling)

  • Max Pooling: Keeps the maximum value in a window (usually 2×2).
  • Benefits: Translation invariance (shifting image slightly doesn't change key features) and 75% data reduction.

Part 3: Implementation in TensorFlow & Keras (20 mins)

3.1 Why Frameworks Matter

  • Automates differentiation (Backpropagation).
  • GPU acceleration for tensor math.
  • Production-ready deployment (TFLite for Jetson).

3.2 Data Dimensions (Channel-Last)

  • Keras/TF order: [Batch, Height, Width, Channels] (NHWC).
  • Contrast with PyTorch's NCHW order.

3.3 The Keras Functional Unit

Code Snippet for students to copy:

layers.Conv2D(32, (3,3), padding='same', activation='relu')
layers.MaxPooling2D((2,2))

Part 4: Shape Transformations (15 mins)

4.1 Calculate the Output Size

The Golden Formula:

$$ O = \lfloor \frac{W - K + 2P}{S} \rfloor + 1 $$

Walk through an example on the board: Input 28x28, Kernel 5x5, No Padding, Stride 1 $\to$ Output 24x24.

4.2 Tracking the MNIST Flow

Input:     [28, 28, 1]    # H, W, C
Conv1:     [28, 28, 6]    # padding='same'
Pool1:     [14, 14, 6]    # 2x2
Conv2:     [10, 10, 16]   # 5x5 filter, valid padding
Pool2:     [5, 5, 16]     # 2x2
Flatten:   [400]          # 5x5x16
Output:    [10]           # Classes

Part 5: LeNet-5 Architecture (10 mins)

  • Yann LeCun (1998): The grandmother of modern CNNs.
  • Structure: Funnel design (Small filters $\to$ Pool $\to$ More filters $\to$ Flat $\to$ Dense).

Lab Preview (5 mins)

Lab Objectives

  1. Define LeNet-5 using models.Sequential().
  2. Compile with optimizer='adam' and loss='sparse_categorical_crossentropy'.
  3. Train using model.fit() on MNIST data.
  4. Export to TFLite for edge deployment.

Summary & Teaching Tips

  • Visualization: Use a physical flashlight or paper cutout to demonstrate "sliding" filters.
  • Common Errors:
    • Forgetting to normalize input (0-255 $\to$ 0-1).
    • Incorrect dimension order (trying to use PyTorch NCHW in Keras).
    • Over-pooling (reducing dimensions to zero).
