WEEK 8

Convolutional Neural Networks (CNNs)

Lecture Notes

Course: Computer Systems Engineering
Module: Artificial Intelligence (AI)
Topic: CNNs with PyTorch
Duration: 90 Minutes

Lecture Outline

Part 1: Introduction to PyTorch (20 mins)

1.1 Why Frameworks Matter

  • Week 7 Limitation: Manual backpropagation

  • Tedious gradient calculations

  • Error-prone implementation

  • CPU-only execution

  • PyTorch Solution:

  • Automatic differentiation (Autograd)

  • GPU acceleration

  • Production-ready deployment

1.2 Core Concepts

Tensors:

  • Multi-dimensional arrays (like NumPy but GPU-enabled)

  • Dimension examples:

  • 0D: Scalar (single number)

  • 1D: Vector [1, 2, 3]

  • 2D: Matrix [[1, 2], [3, 4]]

  • 3D: Image [C, H, W]

  • 4D: Batch [N, C, H, W]

Autograd:

  • Tracks all operations on tensors

  • Builds computational graph

  • loss.backward() computes all gradients automatically

  • Eliminates manual gradient derivation

Demo: Show simple tensor operations and .grad attribute

Part 2: Why CNNs? (15 mins)

2.1 Problems with Fully-Connected Networks

Problem 1: Spatial Ignorance

  • Treats pixels as independent features

  • Loses neighboring pixel relationships

  • Can't exploit 2D structure of images

Problem 2: Parameter Explosion

  • 1000×1000 image → 100 hidden neurons = 100 million weights

  • Impossible to train

  • Guaranteed overfitting

2.2 The CNN Solution

Local Connectivity:

  • Each neuron connects to small local region (receptive field)

  • Drastically reduces parameters

Parameter Sharing:

  • Same filter used across entire image

  • Learn "edge detector" once, apply everywhere

Part 3: CNN Building Blocks (25 mins)

3.1 Convolutional Layer

Operation:

  • Slide small filter (3×3, 5×5) across image

  • Element-wise multiplication + sum

  • Produces feature map

Example: Edge detection filter

[-1  -1  -1]
[ 0   0   0]
[+1  +1  +1]

Detects horizontal edges

Parameters:

  • Filter size (kernel_size)

  • Number of filters (out_channels)

  • Stride (step size)

  • Padding (border handling)

3.2 Pooling Layer

Max Pooling:

  • Take maximum value in window (typically 2×2)

  • Reduces spatial dimensions by 50% each direction

  • 75% data reduction overall

Benefits:

  • Translation invariance

  • Computational efficiency

  • Reduces overfitting

3.3 The Conv-ReLU-Pool Block

Standard Pattern:
1. Conv: Extract features (linear)
2. ReLU: Introduce non-linearity
3. Pool: Reduce dimensions

Hierarchical Learning:

  • Block 1: Edges, textures

  • Block 2: Shapes, patterns

  • Block 3: Objects, parts

Visual: Show feature hierarchy diagram

Part 4: Shape Transformations (15 mins)

4.1 Tracking Dimensions

Critical Skill: Understanding tensor shape flow

Example (MNIST):

Input:     [1, 28, 28]    # 1 channel, 28×28 pixels
Conv1:     [6, 28, 28]    # 6 filters
Pool1:     [6, 14, 14]    # 2×2 pooling
Conv2:     [16, 5, 5]     # 16 filters
Flatten:   [400]          # 16×5×5 = 400
Output:    [10]           # 10 classes

4.2 Common Shape Errors

Error: "RuntimeError: size mismatch"
Cause: Incorrect flattening calculation
Solution: Carefully compute: channels × height × width

Part 5: LeNet-5 Architecture (10 mins)

5.1 Historical Context

  • Yann LeCun, 1998

  • First successful CNN

  • Revolutionized handwriting recognition

5.2 Architecture Details

INPUT (28×28, 1 channel)
    ↓
CONV1 (6 filters, 5×5)
RELU
POOL (2×2)
    ↓
CONV2 (16 filters, 5×5)
RELU
POOL (2×2)
    ↓
FLATTEN
FC1 (120 neurons)
RELU
FC2 (84 neurons)
RELU
OUTPUT (10 classes)

Lab Preview (5 mins)

Lab Objectives

Build LeNet-5 in PyTorch:
1. Define network architecture (nn.Module)
2. Implement forward pass
3. Set up loss function and optimizer
4. Train on MNIST dataset
5. Evaluate accuracy

Key PyTorch Functions

  • nn.Conv2d(): Convolutional layer

  • nn.MaxPool2d(): Max pooling

  • nn.Linear(): Fully connected

  • nn.ReLU(): Activation

  • optimizer.zero_grad(), loss.backward(), optimizer.step()

Summary (5 mins)

Key Takeaways

  1. PyTorch: Automates gradient calculation, enables GPU acceleration
  2. CNNs: Solve image problems via local connectivity and parameter sharing
  3. Conv-ReLU-Pool: Standard building block for feature extraction
  4. Shape Flow: Critical to understand tensor transformations
  5. LeNet-5: Classic CNN architecture, foundation for modern vision
