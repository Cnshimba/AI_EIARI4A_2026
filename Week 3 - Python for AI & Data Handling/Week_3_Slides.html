2. NumPy (Numerical Python)

  • The Array: A high-performance list (C-Contiguous).

  • Vectorization: Doing math on entire lists at once.

  • [1, 2, 3] * 2 $\rightarrow$ [2, 4, 6] (No Loops!)

  • Speed: 50x-100x faster than standard Python loops.

  • Crucial for: Deep Learning matrix multiplications ($Wx + b$).

Section 1 Checkpoint

Summary

  • NumPy replaces slow Python lists with fast C-contiguous arrays

  • Vectorization eliminates loops, speeding up math by 100x

  • Broadcasting allows math between different-shaped arrays

Reflection

Why do we use np.array instead of lists?
Answer: Speed (SIMD) and Memory Efficiency.

3. Pandas (Dataframes)

  • The DataFrame: "Excel inside Python".

  • Loading: df = pd.read_csv("file.csv")

  • Inspecting: .head(), .info(), .describe()

  • Querying: df[df["Age"] > 25] (Boolean Masking).

  • Grouping: df.groupby('City')['Sales'].mean() (Split-Apply-Combine).

4. The 3 Deadly Sins of Data

  1. Missing Values (NaN):

  • Fix: Drop rows OR Impute (fill with Average).
    2. Outliers (Anomalies):

  • Fix: Detect with Histograms/Boxplots and Remove/Clip.
    3. Bad Scaling (0-1 vs 0-1,000,000):

  • Fix: Normalization (Min-Max Scaling).
