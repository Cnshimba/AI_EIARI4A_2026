Lecture Outline

Part 1: Introduction to Unsupervised Learning (20 mins)

1.1 Paradigm Shift

  • Review: Supervised Learning (Weeks 5)

  • Required labeled data (X, Y pairs)

  • Goal: Learn mapping function f(X) → Y

  • Feedback: Loss function measures error

  • Unsupervised Learning:

  • Only input data X (no labels Y)

  • Goal: Discover hidden structures/patterns

  • No explicit "right answer"

  • Feedback: Internal coherence metrics

1.2 Connection to Previous Weeks

Teaching Point: Emphasize that K-Means still uses concepts from Week 2 (Linear Algebra) and Week 3 (Geometry/Distance)

  • Linear Algebra: Computing means (averages) of vectors

  • Geometry: Euclidean distance calculations

  • But no target labels required

1.3 Types of Unsupervised Learning

  1. Clustering (this week's focus)

  • Grouping similar items

  • Example: Customer segmentation

  1. Dimensionality Reduction (future topic)

  • Simplifying high-dimensional data

  • Example: PCA for visualization

  1. Anomaly Detection (future topic)

  • Finding unusual patterns

  • Example: Fraud detection

Part 2: Clustering Fundamentals (15 mins)

2.1 Definition

  • Clustering: Partitioning data into groups (clusters) where:

  • Intra-cluster similarity is HIGH (points in same cluster are similar)

  • Inter-cluster similarity is LOW (points in different clusters are different)

2.2 Real-World Applications

  1. Marketing: Customer segmentation by behavior
  2. Biology: Gene expression grouping
  3. Image Processing: Color quantization/compression
  4. Social Networks: Community detection
  5. Anomaly Detection: Identifying outliers

Part 3: K-Means Algorithm (30 mins)

3.1 Algorithm Overview

Goal: Partition N data points into K clusters

Key Concept: Each cluster represented by a centroid (mean position)

3.2 The K-Means Loop (Detailed)

Step 1: Initialize

  • Randomly select K data points as initial centroids

  • Alternative: K-Means++ initialization (smarter placement)

Step 2: Assign

  • For each data point:

  • Calculate Euclidean distance to all K centroids

  • Assign point to nearest centroid

  • Creates K groups

Step 3: Update

  • For each cluster:

  • Calculate mean position of all assigned points

  • Move centroid to this mean position

  • Mathematical formula: $c_k = \frac{1}{|C_k|} \sum_{x_i \in C_k} x_i$

Step 4: Repeat

  • Go back to Step 2

  • Continue until convergence:

  • Centroids stop moving (position change < threshold)

  • OR maximum iterations reached

Teaching Point: Use the "party speaker" analogy from student notes to make this concrete

3.3 Distance Metric

  • Default: Euclidean distance

  • Formula: $d(p, q) = \sqrt{\sum_{i=1}^{n}(p_i - q_i)^2}$

  • Why it matters: Larger features dominate → normalization important

3.4 Convergence

  • Guaranteed to converge (centroids will eventually stop moving)

  • May converge to local optimum (not global)

  • Solution: Run multiple times with different initializations

Part 4: Choosing K - The Elbow Method (15 mins)

4.1 The Problem

  • K-Means requires K to be specified upfront

  • Too few clusters: Underfitting (groups are too broad)

  • Too many clusters: Overfitting (each point becomes its own cluster)

4.2 Within-Cluster Sum of Squares (WCSS)

  • Metric to measure cluster "tightness"

  • Formula: $WCSS = \sum_{k=1}^{K} \sum_{x_i \in C_k} ||x_i - c_k||^2$

  • Lower WCSS = tighter clusters (better)

4.3 Elbow Method Procedure

  1. Run K-Means for K = 1, 2, 3, ..., 10
  2. Calculate WCSS for each K
  3. Plot K vs. WCSS
  4. Look for the "elbow" point where improvement flattens
  5. Choose K at the elbow

Demo: Show elbow plot, point out steep drop vs. flat region

Part 5: Limitations and Alternatives (10 mins)

5.1 When K-Means Fails

  1. Non-circular clusters: K-Means assumes spherical clusters
  2. Different cluster sizes: K-Means prefers similar-sized clusters
  3. Different densities: K-Means struggles with varying densities
  4. Outliers: Can distort centroids

Teaching Point: Show visual examples of failure cases

5.2 Alternative Algorithms (Brief mention)

  • DBSCAN: Density-based, handles arbitrary shapes

  • Hierarchical Clustering: Creates tree of clusters

  • Gaussian Mixture Models: Probabilistic approach — clusters can be elliptical and overlapping

  • Self-Organizing Maps (SOM): Neural network that produces a low-dimensional topological map

  • Spectral Clustering: Uses graph eigenvalues — ideal for non-convex cluster shapes

Part 6: Cluster Evaluation Metrics (10 mins)

6.1 The Evaluation Challenge

  • No labels → can't use accuracy, precision, recall

  • Must use internal metrics that assess cluster quality from the data itself

6.2 Elbow Method (WCSS)

  • Plot K vs. Within-Cluster Sum of Squares (WCSS) over a range of K values

  • Formula: $WCSS = \sum_{i=1}^{k} \sum_{x \in C_i} ||x - \mu_i||^2$

  • In scikit-learn, access via kmeans.inertia_

  • Pick K at the "elbow" — where improvement flattens

6.3 Silhouette Score

  • Measures how well each point fits its cluster vs. neighbors

  • Formula: $s = \frac{b - a}{\max(a, b)}$ where a = intra-cluster distance, b = nearest-other-cluster distance

  • Range: -1 (bad) to +1 (great). Values near 0 = overlapping clusters

  • In scikit-learn: silhouette_score(X, labels)

Teaching Point: Run both metrics together — Elbow for K selection, Silhouette for validation

Part 7: Distance Metrics (10 mins)

7.1 Euclidean Distance

  • Default for K-Means: $d = \sqrt{\sum(p_i - q_i)^2}$

  • Problem: Sensitive to feature scale — larger features dominate

  • Solution: Always use StandardScaler before clustering

7.2 Cosine Similarity

  • Measures the angle between two vectors: $\cos\theta = \frac{A \cdot B}{||A|| \cdot ||B||}$

  • Range: 0 (orthogonal/different) to 1 (identical direction)

  • Ideal for text and NLP data where document length varies

Part 8: Association Rule Mining (10 mins)

8.1 Definition

  • Discovers interesting relationships between items in large transaction databases

  • Output: Rules of the form If A → then B

8.2 Key Concepts

  • Support: Frequency of itemset. $Support(A) = \frac{\text{Transactions with A}}{\text{Total Transactions}}$

  • Confidence: Reliability of the rule. $Confidence(A \Rightarrow B) = \frac{Support(A \cup B)}{Support(A)}$

8.3 Apriori Algorithm

  • Iteratively finds frequent itemsets by pruning items below a minimum support threshold

  • Application: Market Basket Analysis (e.g., "Customers who buy diapers also buy beer")

Teaching Point: This is often covered in retail and recommender system contexts. Association rules operate on tabular transaction data, not distance-based clustering

Part 9: Live Python Demo (10 mins)

from sklearn.cluster import KMeans
from sklearn.datasets import make_blobs
from sklearn.metrics import silhouette_score
from sklearn.preprocessing import StandardScaler
import matplotlib.pyplot as plt

# Generate data
X, _ = make_blobs(n_samples=500, centers=4, random_state=42)
X_scaled = StandardScaler().fit_transform(X)

# Elbow Method
wcss = [KMeans(n_clusters=k, random_state=42).fit(X_scaled).inertia_ for k in range(1, 11)]
plt.plot(range(1, 11), wcss, marker='o')
plt.title('Elbow Method')
plt.show()

# Final model + Silhouette
kmeans = KMeans(n_clusters=4, random_state=42)
labels = kmeans.fit_predict(X_scaled)
print("Silhouette Score:", silhouette_score(X_scaled, labels))

  • See how centroids migrate to cluster centers

  • Experience impact of choosing wrong K

  • Practice determining optimal K

Summary and Next Steps (5 mins)

Key Takeaways

  1. Unsupervised learning finds patterns without labels
  2. K-Means partitions data using iterative centroid updates
  3. Euclidean distance is the default similarity metric
  4. Elbow Method helps determine optimal K
  5. K-Means works best for circular, similar-sized clusters
