Lab Goal: To understand Clustering by implementing the K-Means algorithm. You will generate synthetic data, visualize how the machine finds patterns, and learn how to pick the perfect $K$ using the Elbow Method.

Why this lab matters:
In the Semester Assignment, you will apply K-Means to complex Network Traffic. In this Lab, we strip away the complexity and use simple "Blobs" to visualize exactly how the algorithm thinks. Seeing the "Centroids" move is the key to understanding Unsupervised Learning.

Part 1: Generating "Fake" Data (Blobs)

Since we don't have labels, it's hard to know if our clustering is working.
Solution: We create Fake Data where we know the answer, but we hide it from the model.

We use make_blobs to generate clusters of points.

import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_blobs

# 1. Generate Data
# n_samples=300: Total points
# centers=4: We want 4 distinct groups
# cluster_std=0.60: How "tight" the clusters are
X, y_true = make_blobs(n_samples=300, centers=4, cluster_std=0.60, random_state=0)

# 2. Visualize it
plt.scatter(X[:, 0], X[:, 1], s=50, c='gray')
plt.title("The Raw Unlabeled Operations Data")
plt.show()
Observation: You (the human) can clearly see 4 groups. Can the machine find them?

Part 2: Running K-Means

Now we import KMeans from sklearn and tell it "Find 4 groups".

from sklearn.cluster import KMeans

# 1. Create the Model
kmeans = KMeans(n_clusters=4)

# 2. Train (Fit)
# Notice we only provide 'X' (Features), not 'y' (Labels)
kmeans.fit(X)

# 3. Get the Results
y_kmeans = kmeans.predict(X)     # Which cluster does each point belong to?
centers = kmeans.cluster_centers_ # Where are the centroids?

# 4. Visualize the Result
plt.scatter(X[:, 0], X[:, 1], c=y_kmeans, s=50, cmap='viridis')
plt.scatter(centers[:, 0], centers[:, 1], c='red', s=200, alpha=0.9, marker='X')
plt.title("K-Means Result (Red X = Centroids)")
plt.show()
Success: The model successfully colored the 4 groups differently, and the Red Xs are perfectly in the center of each group.

Part 3: The Elbow Method (Finding K)

What if we didn't know there were 4 groups?
We run the model for $K=1, 2, 3... 10$ and calculate the Error (Inertia).

inertia = []
K_range = range(1, 11)

for k in K_range:
    model = KMeans(n_clusters=k)
    model.fit(X)
    inertia.append(model.inertia_)

# Plot the Elbow
plt.plot(K_range, inertia, marker='o')
plt.title("The Elbow Method")
plt.xlabel("Number of Clusters (K)")
plt.ylabel("Inertia (Error)")
plt.show()

Task: Look at the graph.

  • At K=1 to K=2: Huge drop (Big improvement).

  • At K=3 to K=4: Comparison drop.

  • At K=4 to K=5: The line becomes flat.

Conclusion: The "Elbow" is at K=4. This tells us the optimal number of clusters is 4.
