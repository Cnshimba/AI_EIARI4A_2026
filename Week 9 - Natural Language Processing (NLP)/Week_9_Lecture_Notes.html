WEEK 9

Natural Language Processing (NLP)

Lecture Notes

Course: Computer Systems Engineering
Module: Artificial Intelligence (AI)
Topic: Text Classification & Word Embeddings
Duration: 90 Minutes

Lecture Outline

Part 1: The NLP Challenge (15 mins)

1.1 Why Text is Different

  • Structured Data (Week 5): Numbers in columns

  • Image Data (Week 8): Pixel grids (still numbers)

  • Text Data: Discrete, variable length, context-dependent

Key Problem: Computers process numbers, not words

1.2 The Representation Challenge

  • Cannot feed "Hello world" directly into matrix multiplication

  • Need mathematical representation of language

  • Must preserve semantic meaning

Part 2: From Words to Numbers (20 mins)

2.1 Tokenization

Definition: Breaking text into atomic units

Example:

"I love AI!" → ["I", "love", "AI", "!"]

Strategies:

  • Word-level: Split on spaces

  • Subword: BPE, WordPiece (used by modern LLMs)

  • Character-level: Individual characters

2.2 Preprocessing Pipeline

  1. Lowercasing: "Apple" → "apple"
  2. Stopword removal: Remove "the", "and", "is"
  3. Stemming/Lemmatization: "running" → "run"

Purpose: Reduce vocabulary size, remove noise

2.3 One-Hot Encoding

Approach: Create vocabulary, assign each word an index

Example (Vocab size = 5):

"cat"   = [1, 0, 0, 0, 0]
"dog"   = [0, 1, 0, 0, 0]
"love"  = [0, 0, 1, 0, 0]

Problems:

  • Sparse (50,000-word vocab → 50,000-dim vectors)

  • No semantic relationships ("cat" vs "dog" equally distant as "cat" vs "car")

  • Memory inefficient

Visual: Show text processing pipeline diagram

Part 3: Word Embeddings Revolution (25 mins)

3.1 The Breakthrough

Idea: Map words to dense, low-dimensional vectors

Example:

  • One-hot: 50,000 dimensions

  • Embedding: 300 dimensions

3.2 How Embeddings Learn Meaning

Distributional Hypothesis (Firth, 1957):

"You shall know a word by the company it keeps"

Training Approach (Word2Vec):

  • Look at context window (±5 words)

  • Words appearing in similar contexts get similar vectors

  • "King" appears near "palace", "crown", "man"

  • "Queen" appears near "palace", "crown", "woman"

  • Network learns "king" and "queen" are geometrically close

3.3 Semantic Arithmetic

Famous Example:
$$\text{King} - \text{Man} + \text{Woman} \approx \text{Queen}$$

Other Examples:

  • Paris - France + Italy ≈ Rome

  • Walking - Walked + Swam ≈ Swimming

Significance: Embeddings capture relationships, not just identity

Demo: Show word embedding visualization (King-Queen diagram)

Part 4: Neural Architectures for Text (20 mins)

4.1 RNNs: The Sequential Approach

Architecture:

  • Process one word at a time

  • Maintain hidden state (memory)

  • Pass information forward

Problems:

  • Vanishing gradients (forgets beginning of long texts)

  • Sequential (cannot parallelize)

  • Slow training

Historical Note: LSTMs improved but didn't solve core issues

4.2 CNNs for Text (TextCNN)

Key Insight: Text is 1D image of word vectors

Operation:

  • 1D convolution slides over word sequences

  • Filters detect n-grams (2-3-4 word phrases)

  • Example: Filter learns "not good" flips sentiment

Advantages:

  • Parallel processing

  • Fast training

  • Detects local patterns effectively

Visual: Show RNN vs CNN comparison

Part 5: Sentiment Analysis Application (10 mins)

5.1 Problem Definition

Task: Classify text as Positive/Negative

Example:

  • "This movie was amazing!" → Positive

  • "Worst film ever." → Negative

5.2 Pipeline

  1. Tokenize: Split into words
  2. Numericalize: Words → IDs (vocabulary lookup)
  3. Embed: IDs → Dense vectors (nn.Embedding)
  4. Aggregate: Average embeddings or CNN
  5. Classify: Linear layer → Sigmoid/Softmax

Lab Preview (5 mins)

Lab Objectives

Build sentiment classifier in PyTorch:
1. Create vocabulary from training data
2. Implement nn.EmbeddingBag (averages word vectors)
3. Add linear classifier
4. Train on positive/negative reviews
5. Evaluate accuracy

Key PyTorch Components

  • nn.Embedding: Lookup table for word → vector

  • nn.EmbeddingBag: Embedding + averaging

  • Simple but powerful for sentiment tasks

Summary (5 mins)

Key Takeaways

  1. Tokenization: First step in NLP pipeline
  2. One-hot: Simple but inefficient
  3. Embeddings: Dense vectors capturing semantic meaning
  4. Semantic Arithmetic: Embeddings encode relationships
  5. TextCNN: CNNs work for text via 1D convolutions

Teaching Tips

  1. Use Examples: Show real tweets/reviews
  2. Live Demo: Tokenize sentence on board
  3. Visualization: Plot 2D projection of word embeddings
  4. Historical Context: Explain RNN → CNN → Transformer evolution
  5. Common Misconceptions:

  • "Embeddings are just compression" → No, they encode meaning

  • "Bigger embedding = better" → Not always, 300 is standard

  • "One-hot is always bad" → Works for small vocabs
