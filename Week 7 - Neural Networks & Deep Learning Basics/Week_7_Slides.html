3. The Perceptron (Neuron)

Anatomy

  • Analogy: Digital mimic of a brain cell.

  • Inputs: Electrical signals ($x$).

  • Weights: Connection strength ($w$).

  • Input Processing:
    $$z = \sum (x \cdot w) + b$$

  • Output: Firing rate (Activation).

4. Activation Functions

Why Non-Linearity?

Linear layers stacked together are just one big linear layer ($y=mx+c$). We need non-linearity to learn curves and complex patterns.

Common Types

  1. Sigmoid:

  • Range: 0 to 1 (Probabilities).

  • Issue: Vanishing Gradient.
    2. ReLU (Rectified Linear Unit):

  • Range: 0 to $\infty$.

  • Rule: "If negative, set to 0."

  • Benefit: Fast, solves vanishing gradient.

5. MLP Architecture

The Structure

  1. Input Layer: The raw data (e.g., 784 pixels).
  2. Hidden Layers: The "Black Box" reasoning. Extracts features.
  3. Output Layer: The final decision (e.g., 10 probabilities for digits 0-9).

Fully Connected: Every neuron in Layer 1 is connected to every neuron in Layer 2.

Section 1 Checkpoint

Summary

  • Perceptron: Inputs * Weights + Bias.

  • Activation: Adds non-linearity (ReLU is king).

  • MLP: Stacking perceptrons into layers creates Deep Learning.

Reflection

6. The Learning Cycle (Backpropagation)

The Loop

  1. Forward Propagation: Guess the answer.
  2. Loss Calculation: Compare guess to truth (Cross Entropy Error).
  3. Backpropagation: Calculate Gradients (Calculus Chain Rule). Find out which weight caused the error.
  4. Update: Nudge weights in opposite direction of gradient.
