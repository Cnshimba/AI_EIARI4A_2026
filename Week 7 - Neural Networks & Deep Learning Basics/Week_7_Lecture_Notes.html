Part 1: From Classical ML to Deep Learning (15 mins)

1.1 Recap of Classical Machine Learning

  • Week 5 - Supervised Learning:

  • Linear Regression: Drew straight lines

  • Logistic Regression: S-curves for classification

  • Decision Trees: Rule-based splitting

  • Week 6 - Unsupervised Learning:

  • K-Means: Found clusters without labels

1.2 Limitations of Classical ML

  • Limited to relatively simple decision boundaries

  • Required manual feature engineering

  • Struggled with high-dimensional data (images, audio, text)

  • Could not learn hierarchical representations

1.3 The Deep Learning Revolution

  • Neural Networks: Inspired by biological neurons

  • Deep: Many layers stacked (hierarchical learning)

  • Automatic feature extraction from raw data

  • State-of-the-art performance in computer vision, NLP, speech

Part 2: The Perceptron - Building Block of AI (20 mins)

2.1 Biological Inspiration

  • Real neurons:

  • Receive signals through dendrites

  • Process in cell body

  • Fire signal through axon if threshold exceeded

  • Artificial neuron (perceptron):

  • Inputs (x) = dendrites

  • Weights (w) = connection strength

  • Weighted sum + bias = cell body processing

  • Activation function = firing threshold

2.2 Mathematical Components

1. Inputs (x)

  • Raw data entering the neuron

  • Example: Pixel values of an image

2. Weights (w)

  • Learned parameters

  • Represent importance of each input

  • Training = finding optimal weights

3. Bias (b)

  • Allows shifting the activation

  • Like intercept in linear regression

  • Enables neuron to fire even when inputs are zero

4. Weighted Sum
$$z = \sum_{i=1}^{n} (x_i \cdot w_i) + b = x_1w_1 + x_2w_2 + ... + x_nw_n + b$$

5. Activation Function
$$a = f(z)$$

Part 3: Activation Functions - The Key to Non-Linearity (20 mins)

3.1 Why Non-Linearity Matters

The Linear Limitation:

  • Without activation: $f(x) = Wx + b$ (linear)

  • Stack 100 linear layers: Still just $f(x) = W'x + b'$ (linear)

  • Network collapses to glorified linear regression

  • Can only learn straight decision boundaries

Non-Linearity Solution:

  • Apply non-linear function at each neuron

  • Network can approximate ANY function (Universal Approximation Theorem)

  • Enables learning circles, curves, complex boundaries

3.2 Common Activation Functions

A. Sigmoid
$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

Properties:

  • Output range: (0, 1)

  • Smooth S-curve

  • Interpretable as probabilities

Problems:

  • Vanishing gradients (saturates at extremes)

  • Not zero-centered

  • Computationally expensive (exponential)

Use cases:

  • Output layer for binary classification

  • Legacy networks (historical)

B. ReLU (Rectified Linear Unit)
$$f(z) = max(0, z) = \begin{cases} z & \text{if } z > 0 \ 0 & \text{if } z \leq 0 \end{cases}$$

Properties:

  • Output range: [0, ∞)

  • Extremely simple (just threshold at zero)

  • Linear for positive values

Advantages:

  • No vanishing gradient for positive values

  • Computationally efficient (just comparison)

  • Sparse activation (many neurons = 0)

  • Default choice for hidden layers

Problems:

  • Dying ReLU: Neurons can become permanently inactive

  • Not zero-centered

Variants:

  • Leaky ReLU: Small negative slope for z < 0

  • Parametric ReLU: Learnable negative slope

  • ELU: Exponential negative region

Part 4: Multi-Layer Perceptron Architecture (15 mins)

4.1 Layer Types

1. Input Layer

  • Passive data reception

  • No computation

  • Size = number of features

  • Example: 784 neurons for 28x28 MNIST images

2. Hidden Layers

  • Where learning happens

  • Extract hierarchical features

  • Layer 1: Simple patterns (edges, textures)

  • Layer 2: Medium complexity (shapes)

  • Layer 3+: High-level concepts (eyes, faces)

  • "Deep" in Deep Learning = Many hidden layers

3. Output Layer

  • Final prediction

  • Size = number of classes (classification) or 1 (regression)

  • Example: 10 neurons for 10 digits (0-9)

4.2 Fully-Connected (Dense) Networks

  • Every neuron in Layer N connects to every neuron in Layer N+1

  • Parameter count explodes:

  • Layer 1 (784 inputs → 128 hidden): 784 × 128 = 100,352 weights

  • Plus 128 biases = 100,480 parameters for one layer!

Part 5: Training Process - Backpropagation (20 mins)

5.1 The Four-Step Cycle

Step 1: Forward Propagation

  • Input flows through network layer by layer

  • At each neuron: $z = Wx + b$, then $a = f(z)$

  • Produces prediction at output layer

  • Example: "I think this image is digit 3 with 50% confidence"

Step 2: Loss Calculation

  • Compare prediction to true label

  • Loss function measures error

  • Common losses:

  • Mean Squared Error (MSE) for regression

  • Cross-Entropy for classification

  • Example: $Loss = (prediction - true)^2$

Step 3: Backpropagation

  • Calculate gradient of loss with respect to each weight

  • Uses Chain Rule of calculus

  • Flows backward through network

  • Assigns "blame" for error to each weight

  • $\frac{\partial Loss}{\partial w}$ = how much does this weight contribute to error?

Step 4: Optimization (Weight Update)

  • Gradient Descent: Move weights opposite to gradient

  • Update rule: $w_{new} = w_{old} - \alpha \cdot \frac{\partial Loss}{\partial w}$

  • $\alpha$ = learning rate (step size)

  • Network becomes slightly better

5.2 The Big Picture

  • Repeat cycle thousands of times

  • Each iteration (epoch) processes entire dataset

  • Network gradually learns optimal weights

  • Loss decreases over time

Lab Preview (5 mins)

Lab Objectives

Build a neural network from scratch using ONLY Python and NumPy:

  1. Affine Layer: Implement $z = Wx + b$ with forward and backward pass
  2. ReLU Layer: Implement activation with forward and backward pass
  3. SoftmaxWithLoss: Convert logits to probabilities and calculate cross-entropy
  4. TwoLayerNet: Assemble complete network
  5. Training Loop: Forward pass, loss, backward pass, update

Why From Scratch?

  • Understand what PyTorch/TensorFlow do under the hood

  • Appreciate automatic differentiation

  • Debug deep learning issues more effectively

  • Truly understand backpropagation mechanics

Summary (5 mins)

Key Takeaways

  1. Perceptron: Basic unit with inputs, weights, bias, and activation
  2. Activation Functions: Introduce non-linearity (ReLU is standard for hidden layers)
  3. MLP Architecture: Input → Hidden layers → Output (fully-connected)
  4. Backpropagation: Forward pass → Loss → Backward pass → Weight update
  5. Deep Learning: Many layers enable hierarchical feature learning

Teaching Tips

  1. Use Analogies:

  • Neuron = decision-making cell

  • Weights = importance multipliers

  • Activation = firing threshold

  • Network = team of specialists

  1. Visual Aids:

  • Draw neurons with arrows

  • Animate forward pass flow

  • Show gradient flowing backward

  • Plot activation functions

  1. Interactive Demos:

  • Live code simple perceptron

  • Show weight updates in real-time

  • Visualize decision boundaries changing

  1. Common Student Misconceptions:

  • "More layers = always better" → No, can overfit

  • "Bigger weights = better" → No, leads to overfitting and instability

  • "Backprop is mysterious" → Just Chain Rule applied systematically

  • "Neural networks think like humans" → No, just mathematical optimization
